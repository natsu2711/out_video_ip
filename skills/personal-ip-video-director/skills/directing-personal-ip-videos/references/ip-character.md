# 个人 IP 角色规范（短发 T 恤女孩 / 火柴人）

本 skill 的角色系统是**双形态**：默认形态是本项目的原创 IP「短发 T 恤女孩」，备选形态是极简火柴人。
每支视频锁定一种形态，从 Phase A 到六条 prompt 保持一致。

## 形态 A（默认）：短发 T 恤女孩

### 角色定义

短发 T 恤女孩是本项目的固定视觉 IP 和出镜主角。

默认每支视频都由她出演。她不是吉祥物，不是贴纸，不是角落里的封面装饰，而是正在亲手推动画面运转的讲解员 / 演示者 / 导演本人。

### 外形锁（每条生成 prompt 必须完整重复）

- 齐耳黑色短发，带不齐碎发刘海。
- 平静的简笔五官：小眼睛、淡表情；情绪靠姿态和肢体，不靠夸张颜艺。
- 宽松深蓝紫色圆领 T 恤，胸前有一枚小图案。
- 深色长裤；不需要鞋部细节。
- 2D 手绘扁平插画：干净的细线描边、少量平涂色、白底；写实偏 Q（约 5–6 头身）。
- 身形、发型、服装、画风在六条片段里完全一致。

参考图（`assets/girl-wave.jpg` / `girl-think.jpg` / `girl-calm.jpg`）：只用于确认角色身份（发型 / 服装 / 画风 / 配色），不要复制参考图的姿势和背景；动作一律按分镜重新设计。生成请求必须附上参考图，并在 prompt 中声明"参考图定义身份，不定义姿势"。

### 性格

- 冷静、认真，有点冷幽默。
- 像在白板前给你拆解一个问题的产品工程师。
- 不卖萌、不夸张、没有网红感。
- 做事有点笨拙但从不失手到失真：摔倒会立刻爬起来，误差会被她亲手修正。

### 常见职责（她必须亲自执行核心动作）

- 搬运、拖拽、堆叠素材块和信息卡片。
- 拉线连接信息源，按下开关，扳动杠杆。
- 把抽象概念具象成实物：扛着、推着、举着走完全程。
- 跳过断点、跨过坑、爬上数据台阶、钻进机器内部操作。
- 被失败结果砸中、被问题包围、被情绪浪潮掀翻（真实承受，不闪避）。
- 完成最后的反转动作：接线、点火、推门、迈出第一步。

### 禁止

- 不要让她只是站在旁边看、躲在角落、当比例尺。
- 不要更换发型、发色、服装、配色或画风。
- 不要写实化、3D 化、精致商业化、儿童卡通化。
- 不要多人同屏抢戏（最多一个次要剪影角色，且她仍是动作主体）。
- 不要让她的戏份挤掉结构表达——先讲清楚，再演出来。

### 判断标准

如果把她从画面里去掉，核心隐喻仍然完全成立，说明她太装饰了；重写提示词，让她成为动作主体。

## 形态 B（备选）：火柴人

沿用极简线稿锁，适合抽象概念、更快节奏、或不想出现人物形象的选题：

- 空心圆头，无脸、无头发、无服装、无填充身体。
- 稳定的人形比例，均匀中等线宽。
- 浅色主题 = 纯白画布 + 黑色线条；深色主题 = 纯黑画布 + 白色线条。
- 与女孩形态同一条纪律：火柴人也是动作主体，不是火柴人剪纸贴在信息图旁边。

## 形态纪律

- 一支视频只用一种形态；切换形态 = 全局变更，Phase A 作废重审。
- 配色：角色自身颜色之外，全片最多三种饱和强调色，用普通语言命名。
- 旁白身份与形态无关，全程一致。
