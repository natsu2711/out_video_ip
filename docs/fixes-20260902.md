# 第四轮：无声成片根因修复 + 稳定性体系（2026-09-03 下午）

> 用户反馈三连：①成片没声音 ②效果单一 ③版式错乱。追查发现全是可机器拦截的确定性 bug。

## 根因一：成片静音（★最严重）

**现象**：vo.wav 完好（-14dB），成片音轨 -91dB（纯静音）。
**根因**：Remotion 分段自带一条**静音音轨**，concat 后 `video-silent.mp4` 同时含
[静音aac轨 + 无声视频]；混音时 ffmpeg **默认流选择**挑中了「48k 立体声」的静音轨，
把 22k 单声道的真人 VO 丢掉了。`-shortest`/loudnorm 都不是凶手（逐一复现排除）。
**修复**：`s6_mix.py` 显式 `-map 0:v:0 -map 1:a:0`（视频=分段，音频=VO），确定性零方差。
**教训**：上一轮"验证通过"只查了时长没查响度——验证不充分等于没验证。

## 根因二：版式错乱

| 组件 | 问题 | 修复 |
|---|---|---|
| StepsCard | 连接线 `position:absolute` 无定位上下文，飞出容器 | 重写：flex 连接线（占位元素）+ 序号逐个点亮 + 当前进度高亮，无绝对定位 |
| TransformCard | 横排 A→B 在 9:16 竖屏挤压 | 重写：竖排上下堆叠 + 下行箭头 + 三拍时序（旧态压缩→箭头→新态爆发），长镜头等比拉伸 |
| ARollScene | 把内部备注原文当字幕展示（"IP 主角视角：…（ComfyUI）…"） | 改展示镜头意图短语 + 视角中文角标 + 地面线收边 |
| 全部 | 长驻期画面完全静止（实测 14 处 2-4.7s 冻结段，这就是"效果单一"的量化证据） | `ShotComposition` 全局层：①Ken Burns 匀速推拉（奇偶镜交替方向，**不用缓动**——缓动首尾速度趋零会被判冻）②锚点色微光漂移（黑底文字镜头也有全画面亮度变化）③TitleCard/TransformCard 加 6s 周期 ±6px 悬浮 |

## 稳定性体系：s6_qa.py 机器验收（7 条硬规则，任一失败 exit 1）

| 规则 | 口径 | 校准依据 |
|---|---|---|
| R1 冻结段 | freezedetect n=0.003 d=2.5，总冻结 ≤5s | 无全局运动历史片 ≈30s+，正常片 ≈3s；d=1.5 会把正常慢速漂移误判（实测正常片逐帧均值差 0.018 < 阈 0.77） |
| R2 响度 | 全片 mean>-35dB 且 max>-15dB | 本轮静音事故直接防线 |
| R2 分窗 | 每 30s 窗口 mean>-35dB | 防「前半静音后半有声」漏网 |
| R3 时长 | vs timing.json 偏差 <800ms | 分段帧数取整累计漂移防线 |
| R4 A-roll 图 | 每镜中点帧亮像素(>200) ≥3% | IP 图 404/空白防线 |
| R5 字幕 | 每镜中点帧字幕带(y90-97%)亮像素 ≥0.15% | 字幕丢失/错位防线 |

# 第五轮：环节化稳定架构（2026-09-03 晚）

> 用户目标：任意文稿 → 稳定高质量出片；模型可随时降级（token 用完换免费/本地）；输出不单一；每环节可单独修改。
> 参考范式：video-talkcraft（schema 契约 + 逐层可换 + 机器可验节拍）、video-shotcraft（重复即廉价 + 六阶段工作流）。

## 新增
- `pipeline/llm.py`：供应商链（openai 兼容端点 → 本地 ollama → 纯规则），JSON 稳出（剥围栏/去尾逗号）+ schema/业务校验 + 错误喂回修复循环。`PIPELINE_LLM_CHAIN` 环境变量切换。
- `pipeline/fallback.py`：纯规则兜底（关键词配卡 + 轮换保多样性 + 规则分句 + 文本节拍提取）。**模型全挂管线也不停**。

- `scripts/s1_script.py`：任意文稿 → script.json（LLM 分句+数字转汉字；规则兜底）。
- `scripts/s3_storyboard.py`：四层架构（L1 规则分组 → L2 逐镜 LLM 小任务配卡（单镜失败单镜降级）→ L3 规则装配 → L4 lint+确定性一次收敛重排）。
- `scripts/pipeline.py`：S1/S3 接入状态机 + `--force` 单环重跑。
- `docs/contracts.md`：全部契约 + 替换指引。
- ShotComposition 支持配方短名；storyboard.schema.json 填 enum（契约闭环）。
